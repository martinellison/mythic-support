# CONTRIBUTING

The Mythic Game Master Emulator plugin is a plugin for the [[../../Reference/Technical/Obsidian|Obsidian]] note-taking application.

Please see:

* [[https://obsidian.md/|the Obsidian documentation]]
* [[https://docs.obsidian.md/Plugins/Getting+started/Build+a+plugin|Obsidian plug-ins]]
* [[https://deepwiki.com/obsidianmd/obsidian-developer-docs/4-api-reference|Unofficial  Obsidian API reference]]

Please see the [[./README.md|README.md]] that accompanies this document for a reference to the release licence.

The source code for this plugin is to be found on GitHub at [[https://github.com/martinellison/mythic-support|here]]. Please use the Discussions, Issues, Wiki and Pull Requests tabs as appropriate.

No "artificial intelligence" has been used to create the plugin.
