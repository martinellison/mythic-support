# Plugin to support Mythic Game Master Emulator

This plugin is used to support the Mythic Game Master Emulator on Obsidian.

This work is based on Mythic Game Master Emulator Second Edition by Tana Pigeon, published by Word Mill Games, and licensed for our use under the Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0) license. Find out more at www.wordmillgames.com.

This is not an official product of Word Mill Games.

## Using this plugin

See ["How to write your own adventure.md"] in this folder for advice on how to install and use this plugin.

The project is hosted at https://github.com/martinellison/mythic-support, which includes the source code for this plugin.

Please use the Discussions tab on the GitHub page for any queries and general discussion, and the Issues tab for any specific defects or proposed enhancements. If you have any specific changes, the CONTRIBUTING.md file in the source tree provides further information.
